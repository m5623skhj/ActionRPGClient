# Assets 디렉터리

게임에서 사용하는 데이터와 미디어 파일은 C++ 소스와 분리해 이 디렉터리에 보관합니다.

| 경로 | 용도 |
| --- | --- |
| `Data/assets.ini` | 데이터·이미지·오디오의 논리적 ID와 상대 경로 연결 |
| `Data/animations.ini` | 스프라이트 시트 구성, 재생 속도, 표시 크기 |
| `Data/projectiles.ini` | 직선·포물선 투사체의 이동, 수명, 표시 방식 |
| `Data/skills.ini` | 스킬 입력 순서와 시간 제한 |
| `Data/effects.ini` | 스킬과 시각·청각 효과의 연결 |
| `Data/system_menu.ini` | ESC 전체 메뉴의 아이콘 순서, 라벨, 실행할 UI 연결 |
| `Images/` | 캐릭터, 마을 배경, 이펙트 이미지 |
| `Audio/` | 음악과 효과음 |

`ActionRPGClient`를 빌드하면 이 디렉터리 전체가 실행 파일 옆의 `Assets/`로 복사됩니다. 실행 중에는 현재 작업 디렉터리가 아닌 **실행 파일 위치**를 기준으로 경로를 찾습니다. `assets.ini`에 등록하는 경로는 `Assets/` 기준 상대 경로로 작성합니다.

마을 맵 JSON의 `images[].asset`도 `Assets/` 기준 상대 경로입니다. 마을 배경 이미지는 이 값을 직접 사용하므로 `assets.ini`의 `[Images]`에 별도로 등록할 필요가 없습니다.

스프라이트 셀의 `anchor_y`는 캐릭터의 지면 좌표에 맞출 세로 기준점을 0~1 범위로 나타냅니다. 모든 프레임의 발 위치를 같은 기준에 맞춰야 애니메이션 중 캐릭터가 위아래로 흔들리지 않습니다. 두 번째 행의 여백이 다르면 `second_row_anchor_y`로 해당 행의 기준점을 덮어쓸 수 있습니다. 프레임마다 가로 배치가 불규칙하면 `anchor_xs`에 프레임별 가로 기준점을 지정합니다.

## 캐릭터 공통 동작

`Player`는 `Character`를 상속합니다. 이동, 점프, 지상·공중 공격의 예약과 발사 시점,
반동, 피격·쓰러짐·기상 상태 전환 및 애니메이션 재생은 `Character`에서 처리합니다.
키보드 입력과 방향키 두 번 누르기, 커맨드 스킬 효과, 서버 위치 보정은 `Player`에 남깁니다.

몬스터를 구현할 때도 `Character`를 상속하고 AI의 판단을 `CharacterActions`로 변환해
`UpdateActions`에 전달합니다. `moveDirection`은 이동 방향, `run`과 `jump`는 달리기·점프 요청,
`attackPressCount`는 이번 업데이트에서 추가할 공격 횟수입니다.
`projectileType`은 기존 V 투척처럼 공격 애니메이션과 별도로 투사체를 요청할 때 사용합니다.
발사 시점에 생성된 `CharacterProjectileRequest`는 월드가 받아 실제 투사체를 생성합니다.
투사체 데이터 ID는 월드에서 캐릭터 종류에 맞게 연결하며 공통 클래스에 플레이어 전용 ID를 넣지 않습니다.

각 캐릭터는 생성 시 `CharacterAnimationSet`에 현재 동작별 애니메이션 섹션을 모두 지정합니다.
같은 상태 처리와 별도의 이미지·재생 속도를 사용할 수 있으며, 발사 섹션은 `event_frame`을 지정해야 합니다.
현재 공통 공격 동작은 기존 지상·공중 연속 사격 방식입니다.
캐릭터 상태 변경, 업데이트, 렌더링, 투사체 요청 소비는 게임 스레드에서 처리합니다.
다른 스레드에서 발생한 플레이어 피격은 기존 `GameWorld::QueuePlayerHit` 큐를 거칩니다.

## X 연속 사격

공격 버튼 X를 누를 때마다 한 발을 예약하며, 첫 발을 포함해 한 동작에서 최대 5발까지 발사합니다. 버튼을 누르고 있는 것만으로 추가 발사가 예약되지는 않습니다.

| 이미지 | 원본 프레임 | 역할 |
| --- | --- | --- |
| `player_shoot_start.png` | 1~2 | 총 들기·조준 |
| `player_shoot_fire.png` | 3~5 | 발사·반동·복귀, 추가 입력이 있으면 반복 |
| `player_shoot_end.png` | 6 | 총 내리기 |

분리된 시트는 `player_shoot.png`의 픽셀과 셀 크기를 그대로 사용합니다. 발사 구간의 첫 프레임에서 탄환을 한 번 생성하며, 각 프레임은 0.070초 동안 표시합니다. 총을 내리는 도중 들어온 추가 입력은 같은 5발 한도 안에서 마무리 후 준비 구간을 거쳐 이어집니다. 한도에 도달한 추가 입력은 저장하지 않습니다.

## 점프와 공중 사격

C 입력은 무릎을 굽히고 펴는 3프레임 준비 동작 후 도약합니다. 공중에서는 4번 점프 자세를 고정하고 높이만 물리 계산으로 변경합니다. 착지는 원본 점프 프레임 4→3→2→1을 재사용합니다.

| 이미지 | 구성 |
| --- | --- |
| `player_jump_start.png` | 원본 점프 1~3번 |
| `player_jump_hold.png` | 원본 점프 4번, 공중 고정 |
| `player_jump_land.png` | 원본 점프 4→3→2→1 |
| `player_air_shoot_start.png` | 공중 조준 준비 2프레임 |
| `player_air_shoot_fire.png` | 아래 45도 발사·반동·복귀 3프레임 |
| `player_air_shoot_end.png` | 공중 사격 마무리 1프레임 |

점프 준비 중 또는 공중에서 X를 누르면 공중 사격을 예약합니다. 한 번의 점프에서 총 5발까지 허용하며, 공중 사격 동작이 끝나도 횟수는 유지합니다. 반복 발사의 간격은 0.135초이며, 착지하면 남은 공중 사격 예약을 취소합니다. 점프를 시작하면 진행 중인 지상 사격과 그 예약을 정리합니다.

공중 발사마다 높이를 3만큼 올리고 상승 속도를 35만큼 추가하며, 바라보는 방향의 반대로 지면 좌표를 4만큼 이동합니다. 이 값은 클라이언트 월드 단위이고 `Character.h`의 `AIR_SHOT_RECOIL_*` 상수에 정의합니다. 이동 제한은 반동에도 적용합니다. 공중 탄환은 `PlayerAirBullet`의 동일한 가로·하강 속도로 45도 이동하고 지면에 도달하면 사라집니다.

## 피격, 에어본, 쓰러짐과 기상

충돌 판정 또는 서버 이벤트 처리부는 `GameWorld::QueuePlayerHit(CharacterHitType::Normal)` 또는
`GameWorld::QueuePlayerHit(CharacterHitType::Airborne)`를 호출합니다. 큐는 뮤텍스로 보호하며
실제 플레이어 상태 변경은 다음 `GameWorld::Update`의 게임 스레드에서만 처리합니다.
현재 프로젝트에는 적의 타격 판정/서버 피격 패킷 생성부가 없어 이 진입점에 연결해야 합니다.

| 피격 상황 | 처리 |
| --- | --- |
| 지상 + 일반 공격 | 일반 경직 4프레임을 한 번 재생 |
| 지상 + 에어본 공격 | 떠오름 → 낙하 → 바닥에 쓰러짐 → 일어남 |
| 공중 + 모든 공격 | 상승을 중단하고 즉시 하강 → 쓰러짐 → 일어남 |
| 쓰러진 상태 + 일반 공격 | 서 있는 경직으로 바꾸지 않고 쓰러짐 유지 시간을 갱신 |
| 일어나는 중 + 일반 공격 | 다시 쓰러짐으로 전환 |

피격은 점프 준비/착지, 지상·공중 연속 사격과 미처 발사하지 않은 예약을 취소합니다.
경직/낙하/쓰러짐/기상 중에는 이동, C 점프, X 사격, V 투척, 커맨드 스킬을 받지 않고
마을 서버에도 이동 방향 0을 보냅니다. 피격 이전 커맨드 입력 이력도 비웁니다.
맵을 바꾸면 피격, 점프, 공격 상태와 남은 피격 이벤트를 초기화합니다.

일반 경직은 0.280초입니다. 지상 에어본 상승 속도는 560, 중력은 1800이며,
공중 피격 시 세로 속도는 최소 하강 속도 500으로 바뀝니다.
더 빠르게 내려가고 있었다면 기존 하강 속도를 유지합니다. 낙하 중에는 자세를 고정하고
실제 높이가 0이 된 시점부터 쓰러짐 2프레임(0.200초), 쓰러진 자세 유지(0.250초),
기상 3프레임(0.330초)을 순서대로 처리합니다.

`player_hit.png`의 셀은 256×256이고, 나머지 피격 시트의 셀은 320×256입니다.
가로로 누운 자세를 담은 시트는 `render_width=252.5`, `render_height=202`로
표시하여 기존 256×256 시트와 캐릭터의 크기를 동일하게 유지합니다.
분리된 `PlayerAirHitStart`, `PlayerAirHitFall`, `PlayerKnockdown`, `PlayerGetUp`를
상태별로 사용하고, 전체 8프레임 `player_air_hit.png`는 원본 동작 보관용입니다.

## ESC 전체 메뉴 아이콘

메뉴 아이콘 이미지는 `Images/UI/`에 두고 `Data/assets.ini`의 `[Images]`에 논리 ID를 등록합니다. 이후 `Data/system_menu.ini`에 섹션을 추가하면 해당 순서대로 전체 메뉴에 배치됩니다. 원본 이미지 크기와 관계없이 모든 메뉴 아이콘은 화면에서 `128x128` 크기로 그려지며, 항목이 화면 높이를 넘으면 마우스 휠 스크롤이 자동으로 활성화됩니다.

현재 사용할 수 있는 `Action` 값은 `Party`, `Exit`입니다. 새로운 UI를 추가할 때 해당 UI 동작을 구현한 뒤 새 Action과 설정 섹션을 함께 등록합니다.
