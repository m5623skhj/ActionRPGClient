# Town Map Editor 사용 설명서

Town Map Editor는 여러 장의 마을 배경 이미지를 월드에 배치하고, TownServer가 사용하는
이동 가능 영역과 진입 금지 영역, 플레이어 시작 위치를 작성하는 도구입니다.

## 1. 빌드

Visual Studio 2022에서 `ActionRPGClient.slnx`를 열고 다음 프로젝트를 빌드합니다.

- 프로젝트: `TownMapEditor`
- 구성: `Debug` 또는 `Release`
- 플랫폼: `x64`

Debug 빌드 결과는 다음 경로에 생성됩니다.

```text
artifacts/bin/x64/Debug/TownMapEditor.exe
```

## 2. 실행

편집기는 다음 두 실행 인자를 받습니다.

```text
TownMapEditor.exe [맵 JSON 경로] [클라이언트 Assets 경로]
```

TownServer가 실제로 읽는 맵을 편집하는 예시는 다음과 같습니다.

```powershell
artifacts/bin/x64/Debug/TownMapEditor.exe `
  C:\Users\KimHyeongJin\source\repos\ActionRPGServer\ActionRPGServer\TownServer\Data\TownMap.json `
  C:\Users\KimHyeongJin\source\repos\ActionRPGClient\ActionRPGClient\Assets
```

- 첫 번째 인자는 불러오고 저장할 맵 JSON 경로입니다.
- 두 번째 인자는 클라이언트의 `Assets` 디렉터리입니다.
- 두 번째 인자를 생략하면 실행 파일 위치를 기준으로 프로젝트의 `Assets` 디렉터리를 찾습니다.
- 첫 번째 인자를 생략하면 현재 작업 디렉터리의 `TownMap.json`을 사용합니다.

기존 파일이 있으면 시작할 때 자동으로 불러옵니다. 지정한 맵 파일이 없다면 기본 맵으로
시작하며, 처음 저장할 때 해당 경로에 파일을 생성합니다.

실행 후 다른 맵을 편집하려면 `O Open Map` 버튼 또는 `O` 키를 누르고 기존 JSON 파일을
선택합니다. 불러온 파일이 이후 `Save`의 저장 대상이 됩니다.

## 3. 기본 작업 순서

1. 배경 이미지를 추가하고 월드 좌표에 배치합니다.
2. `Walkable` 모드에서 캐릭터가 이동할 수 있는 영역을 작성합니다.
3. 필요한 경우 `Blocked` 모드에서 이동 가능 영역 내부의 장애물을 작성합니다.
4. `Spawn` 모드에서 플레이어 시작 위치를 지정합니다.
5. `Visible Area` 모드에서 실제 게임 화면에 표시할 전체 영역을 지정합니다.
6. `Save` 또는 `Save As...`로 TownServer용 JSON 파일을 저장합니다.

## 4. 이미지 추가와 배치

### Add at X/Y

1. 오른쪽 패널의 X와 Y에 배치할 월드 좌표를 입력합니다.
2. `Add at X/Y`를 누릅니다.
3. PNG, JPG, JPEG 또는 BMP 이미지를 선택합니다.

선택한 이미지는 입력한 좌표에 원본 픽셀 크기로 배치됩니다. 추가된 이미지는 자동으로
선택 상태가 됩니다.

### 방향별 이어 붙이기

`Add Right`, `Add Bottom`, `Add Top`, `Add Left`는 선택한 이미지를 기준으로 새 이미지를
각 방향에 간격 없이 이어 붙입니다.

```text
Right:  (기준 X + 기준 너비, 기준 Y)
Bottom: (기준 X, 기준 Y + 기준 높이)
Top:    (기준 X, 기준 Y - 새 이미지 높이)
Left:   (기준 X - 새 이미지 너비, 기준 Y)
```

예를 들어 기준 이미지가 X=0, Y=0이고 크기가 100x100이라면 같은 크기의 이미지는
Right `(100, 0)`, Bottom `(0, 100)`, Top `(0, -100)`, Left `(-100, 0)`에 배치됩니다.

- 선택한 이미지가 있으면 해당 이미지가 기준입니다.
- 선택한 이미지가 없으면 마지막으로 추가된 이미지가 기준입니다.
- 이미지가 하나도 없으면 모든 방향 버튼이 오른쪽 패널의 현재 X/Y 입력 위치를 사용합니다.

### 이미지 선택과 위치 수정

1. `V Select` 버튼을 누르거나 `V` 키를 누릅니다.
2. 캔버스에서 이미지를 클릭합니다.
3. 노란색 테두리가 표시되면 다음 방법으로 위치를 수정합니다.

- 마우스 좌클릭 드래그: 자유 이동
- X/Y 값 입력 후 `Apply Position`: 정확한 좌표로 이동
- X/Y 입력란에서 `Enter`: 입력 좌표 적용
- 방향키: 1 단위 이동
- `Shift+방향키`: 10 단위 이동
- `Delete`: 선택 이미지 삭제

이미지가 겹치면 나중에 추가된 이미지가 먼저 선택됩니다.

### 이미지 파일 관리

추가한 이미지는 자동으로 다음 디렉터리에 복사됩니다.

```text
Assets/Images/Towns
```

같은 이름의 다른 파일이 이미 있으면 파일명 뒤에 번호를 붙여 별도 저장합니다. 맵 JSON에는
Assets 디렉터리를 기준으로 한 상대 경로가 기록됩니다.

## 5. 이동 가능 영역 작성

1. `W Walkable` 버튼을 누르거나 `W` 키를 누릅니다.
2. 이동 가능 영역의 꼭짓점을 순서대로 좌클릭합니다.
3. 점을 3개 이상 입력한 뒤 `Enter`를 눌러 다각형을 완성합니다.

여러 개의 이동 가능 다각형을 만들 수 있습니다. 캐릭터는 이동 가능 다각형 내부에서만
움직일 수 있습니다.

- `Backspace`: 현재 작성 중인 마지막 점 취소
- 다른 편집 모드 선택: 현재 작성 중인 다각형 취소
- `Clear Mode Areas`: 저장된 모든 이동 가능 영역 삭제

모드 버튼을 클릭한 뒤 캔버스에 점을 추가하면 키보드 포커스가 자동으로 캔버스로
돌아오므로 `Enter`와 `Backspace`를 바로 사용할 수 있습니다.

`Clear Mode Areas`는 현재 `Walkable` 모드일 때만 이동 가능 영역을 삭제합니다.

## 6. 진입 금지 영역 작성

1. `B Blocked` 버튼을 누르거나 `B` 키를 누릅니다.
2. 장애물의 꼭짓점을 순서대로 좌클릭합니다.
3. 점을 3개 이상 입력한 뒤 `Enter`를 눌러 다각형을 완성합니다.

진입 금지 영역은 이동 가능 영역보다 우선합니다. 따라서 이동 가능 영역 안에 집, 벽,
장식물과 같은 장애물을 배치할 때 사용합니다.

- `Backspace`: 현재 작성 중인 마지막 점 취소
- 다른 편집 모드 선택: 현재 작성 중인 다각형 취소
- `Clear Mode Areas`: 저장된 모든 진입 금지 영역 삭제

`Clear Mode Areas`는 현재 `Blocked` 모드일 때만 진입 금지 영역을 삭제합니다.

## 7. 시작 위치 배치

다음 두 방법 중 하나로 플레이어 시작 위치를 지정할 수 있습니다.

- `P Spawn` 버튼 또는 `P` 키를 누른 뒤 캔버스를 좌클릭
- 편집 모드와 관계없이 캔버스를 우클릭

타원이 시작 위치의 실제 캐릭터 충돌 범위를 나타냅니다. 유효하면 초록색, 잘못된 위치면
빨간색으로 표시됩니다. 시작 위치와 충돌 범위는 표시 영역과 이동 가능 영역 안에 있어야
하며 진입 금지 영역과 겹치면 안 됩니다.

## 8. 전체 표시 영역 지정

1. `R Visible Area` 버튼을 누르거나 `R` 키를 누릅니다.
2. 실제로 표시할 사각형의 한쪽 모서리에서 반대쪽 모서리까지 좌클릭 드래그합니다.
3. 청록색 테두리 안쪽이 클라이언트에서 표시되는 전체 마을 영역입니다.

에디터에서는 배치 작업을 위해 영역 밖 이미지도 어둡게 표시하지만, 실제 클라이언트에서는
영역 밖 부분을 출력하지 않습니다. 배경 이미지는 표시 영역보다 커도 되지만 Walkable,
Blocked, Spawn은 표시 영역 안에 있어야 합니다. 표시 영역은 서버의 최외곽 이동 경계로도
사용됩니다.

## 9. 캔버스 탐색

- 마우스 가운데 버튼 드래그: 캔버스 이동
- `Space+좌클릭` 드래그: 캔버스 이동
- 마우스 휠: 커서 위치를 중심으로 확대·축소
- `F Fit All` 버튼 또는 `F` 키: 모든 이미지와 영역이 보이도록 맞춤

`Fit All`은 편집 화면의 카메라만 조정하며 지정한 표시 영역은 변경하지 않습니다.

## 10. 저장

`S Save` 버튼 또는 `S` 키를 누르면 현재 맵 JSON 경로에 저장합니다.
`Shift+S Save As...` 버튼 또는 `Shift+S`를 누르면 파일 이름과 경로를 새로 지정하여
저장합니다. 다른 이름으로 저장에 성공하면 선택한 파일이 현재 맵 경로가 되므로 이후
`Save`는 새 파일을 갱신합니다. 파일 선택을 취소하거나 저장 검증에 실패하면 기존 저장
경로를 유지합니다. 기존 파일을 선택하면 덮어쓸지 확인합니다.

저장하려면 다음 조건을 만족해야 합니다.

- 작성 중인 다각형이 없어야 합니다.
- 유효한 전체 표시 영역이 지정되어 있어야 합니다.
- 완성된 이동 가능 다각형이 하나 이상 있어야 합니다.
- 모든 이동 영역의 꼭짓점이 표시 영역 안에 있어야 합니다.
- 시작 위치와 캐릭터 충돌 범위가 유효한 이동 영역 안에 있어야 합니다.
- 이동 가능 영역과 진입 금지 영역의 전체 꼭짓점 수가 32,768개 이하여야 합니다.

저장에 성공하면 창 제목에 저장된 파일 경로가 표시됩니다.

## 12. 제한 사항

- 이미지: 최대 2,048개
- 한 다각형의 꼭짓점: 최대 2,048개
- 전체 다각형 꼭짓점: 최대 32,768개
- 이미지 에셋 상대 경로: UTF-8 기준 최대 240바이트
- 지원 이미지: PNG, JPG, JPEG, BMP
- 지원 맵 형식: 버전 1 읽기, 버전 2 읽기 및 저장

버전 1 맵을 불러온 뒤 저장하면 버전 2 형식으로 저장됩니다.
기존 `sectorSize` 맵을 불러와 저장하면 기본 1280×720 직사각형 섹터의
`sectorWidth`와 `sectorHeight` 형식으로 저장됩니다.

## 13. 서버와 클라이언트에 반영

TownServer의 실제 맵 파일을 직접 열어 저장했다면 서버를 다시 시작해야 변경된 이동 영역이
반영됩니다.

```text
ActionRPGServer/ActionRPGServer/TownServer/Data/TownMap.json
```

새 이미지를 추가했다면 클라이언트를 다시 빌드해 변경된 `Assets`를 실행 파일 옆으로
복사합니다. 맵의 이미지 좌표는 클라이언트 렌더링에 사용되고, 이동 가능·진입 금지 영역과
시작 위치는 TownServer의 이동 판정에 사용됩니다.

배경 이미지는 전체 표시 영역보다 크게 배치할 수 있습니다. 클라이언트는 이미지와 표시
영역이 겹치는 부분만 그리며 바깥쪽은 출력하지 않습니다.

현재 마을에서는 `runSpeed` 값이 JSON에 남아 있어도 서버와 클라이언트 모두 걷기만
허용합니다. 실제 이동 속도는 `walkSpeed`를 사용합니다.

## 14. 저장 오류 해결

### Finish or cancel the current polygon or visible area before saving

작성 중인 다각형 또는 표시 영역 드래그가 남아 있습니다. 다각형은 점을 세 개 이상 추가한
뒤 `Enter`로 완성하고, 취소하려면 다른 모드를 선택합니다. 표시 영역은 드래그를 끝냅니다.

### The visible area must have a positive width and height

표시 영역이 지정되지 않았거나 너비 또는 높이가 0입니다. `R Visible Area` 모드에서 실제로
보여 줄 영역을 다시 드래그합니다.

### At least one completed walkable polygon is required

완성된 Walkable 다각형이 없습니다. 점을 세 개 이상 추가하고 `Enter`로 완성합니다.

### Spawn 관련 오류

오류 메시지는 Spawn 중심 또는 충돌 범위가 표시 영역, Walkable, Blocked 중 어느 조건에
걸렸는지 구분해 표시합니다. 빨간색 Spawn 타원 전체가 청록색 표시 영역과 Walkable 안에
들어가고 Blocked와 겹치지 않도록 다시 배치합니다.

### All polygon vertices must be inside the visible area

Walkable 또는 Blocked 꼭짓점이 표시 영역 밖에 있습니다. 표시 영역을 넓히거나 다각형을
영역 안에서 다시 작성합니다.

### The map exceeds the 32768 polygon vertex limit

다각형의 전체 꼭짓점이 너무 많습니다. 불필요한 점을 줄이거나 영역을 단순화합니다.

### 이미지가 붉은 사각형으로 표시됨
